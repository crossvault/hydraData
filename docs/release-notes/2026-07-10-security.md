# Security release note - 2026-07-10

Connection strings are no longer exposed through the script-facing `IConnection` API. The
`IConnection.ConnectionString` member has been removed; safe-mode scripts can still inspect a
connection's `Id`, `Name`, and `DbType` through `CurrentConnection`, `GetConnection`, `GetById`, or
`Where`.

This is a source- and binary-breaking security hardening for scripts or compiled consumers that
referenced `IConnection.ConnectionString`. `ConnectionInfo.ConnectionString` remains available to
trusted host code and the engine's database gateway. A trusted script could still cast a returned
handle to the concrete `ConnectionInfo` type; safe-mode is an API-surface guard, not a sandbox for
hostile scripts.
