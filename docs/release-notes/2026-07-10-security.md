# Security release note - 2026-07-10

`IConnection.ConnectionString` has been removed from the script-facing API. Safe-mode scripts can
still inspect a connection's `Id`, `Name`, and `DbType`, but can no longer read provider connection
strings or embedded credentials through `CurrentConnection`, `GetConnection`, `GetById`, or `Where`.

This is a source-breaking security hardening for scripts that referenced
`IConnection.ConnectionString`. `ConnectionInfo.ConnectionString` remains available to trusted host
code and the engine's database gateway. A trusted script could still cast a returned handle to the
concrete `ConnectionInfo` type; safe-mode is an API-surface guard, not a sandbox for hostile scripts.
