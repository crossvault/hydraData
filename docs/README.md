# HydraData Documentation

HydraData is an embeddable, script-driven data pump for .NET 10. It can run as
a console host or be embedded through `HydraData.Engine`.

## Project Layout

- `src/HydraData.Engine` - embeddable engine package
- `src/HydraData.Host` - console host
- `test/*` - unit and integration tests
- `docs/*` - public user documentation
